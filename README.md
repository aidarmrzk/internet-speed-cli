# Internet Speed CLI

Консольный скрипт для замера средней скорости скачивания по заданному HTTP(S)-адресу. Делает 10 последовательных GET-запросов и полностью считывает тело каждого ответа.

## Запуск

Нужен Node.js 22 или новее. Устанавливать зависимости не требуется. Из папки репозитория запустите команду, подставив прямой URL файла.

```sh
node speed.mjs "https://example.com/large-image.jpg"
```

Для замера выберите достаточно большой статический файл, например изображение размером в несколько мегабайт.

## Как считается результат

- **Average request time** — среднее время одного запроса в миллисекундах, от начала запроса до полного чтения тела ответа.
- **Total downloaded** — суммарный размер прочитанных тел ответов в байтах. Скрипт запрашивает ответ без HTTP-сжатия и считает байты по мере чтения, не сохраняя файл в памяти целиком. Если сервер всё же применяет сжатие, встроенный `fetch` возвращает распакованное тело.
- **Download speed** — суммарный объём в битах, поделённый на суммарное время запросов в секундах и на 1 000 000. Единица измерения — Мбит/с (Mbit/s).

Результат включает задержку до начала передачи и зависит от выбранного сервера. При сетевой ошибке, неуспешном HTTP-статусе или превышении таймаута в 60 секунд скрипт выводит ошибку и завершается с кодом 1.
